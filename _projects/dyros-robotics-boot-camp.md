## Project Description

The DYROS Robotics Boot Camp is an educational program run by the [Dynamic Robotics Systems Lab](http://dyros.snu.ac.kr/features/about-us/) at Seoul National University, offering lectures on:

- ROS (Robot Operating System)
- Linux
- Robot simulators
