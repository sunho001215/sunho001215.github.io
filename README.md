# sunho001215.github.io

Personal homepage of Sunho Kim, served at <https://sunho001215.github.io>.

The site is a small custom Jekyll site with no external theme. GitHub Pages builds it automatically
on every push to `master`.

## Editing content

Most content is plain YAML or Markdown:

| What | Where |
| --- | --- |
| Name, contact info, CV link, analytics | `_config.yml` (`author:` block) |
| Bio | `index.html` (the `#about` callout) |
| Education | `_data/education.yml` |
| Publications | `_data/publications.yml` (your name is bolded automatically) |
| Research / work experience | `_data/research_experience.yml`, `_data/work_experience.yml` |
| Honors and awards | `_data/awards.yml` |
| Teaching, military service | `_data/teaching.yml`, `_data/military_service.yml` |
| Skills | `_data/skills.yml` |
| Projects | `_projects/*.md` (one file per project) |
| Project tag colors | `_data/tag_colors.yml` |

Section order on the home page is defined in `index.html`.

### Adding a project

1. Put images in `assets/img/projects/<slug>/` (at least a `cover.jpg`) and videos in `assets/video/`.
2. Create `_projects/<slug>.md`:

   ```markdown
   ---
   title: My New Project
   description: One-line subtitle shown on the card
   summary: One or two sentences used for search engines and link previews.
   start_date: 2026-03-01    # start date (projects are sorted by this, newest first)
   end_date: present         # or a date such as 2026-08-31
   tags: [Robotics, Computer Vision]
   cover: /assets/img/projects/my-new-project/cover.jpg
   cover_position: 50%       # vertical focus of the card cover (0% = top, 100% = bottom)
   ---

   ## Project Description

   Text in Markdown...

   {% include figure.html src="/assets/img/projects/my-new-project/result.png" caption="Result" %}
   {% include video.html src="/assets/video/my-new-project.mp4" poster="/assets/img/projects/my-new-project/poster.jpg" %}
   {% include youtube.html id="VIDEO_ID" title="Demo video" %}
   ```

   The page is published at `/projects/<slug>/` and appears in the gallery automatically.

## Local preview

With Docker (no local Ruby needed):

```bash
docker run --rm -it -p 4000:4000 -v "$PWD":/srv/site -w /srv/site ruby:3.3 \
  bash -c "bundle install && bundle exec jekyll serve --host 0.0.0.0"
```

Then open <http://localhost:4000>. With Ruby installed locally, `bundle install && bundle exec jekyll serve` works too.

## Search engines

- `sitemap.xml` and `robots.txt` are generated by `jekyll-sitemap`.
- Each page has a description, canonical URL, and Open Graph tags; the home page also has `Person` structured data (JSON-LD).
- To verify the site in [Google Search Console](https://search.google.com/search-console), choose the "HTML tag" method,
  copy the `content` value into `google_site_verification` in `_config.yml`, push, and then submit `https://sunho001215.github.io/sitemap.xml`.
